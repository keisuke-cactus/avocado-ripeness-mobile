# アボカド熟成度アプリ（スマホ対応版）

修了確認済み版とは別の公開用コピーです。

Streamlit Community Cloudでapp.pyを指定して実行します。Python 3.13を指定してください。
モデルはCPUで推論します。画像入力はファイル選択とカメラ撮影に対応。

テスト正解率65.7%（3026枚）。店頭での性能は未検証。食用の安全性は判断できません。

データ出典：https://data.mendeley.com/datasets/3xd9n945v8/1
